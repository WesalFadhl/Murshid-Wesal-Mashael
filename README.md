## 📌 Project Overview

**Murshid** is a bilingual (Arabic–English) service assistant developed to explore the fundamental principles of Large Language Model (LLM) application engineering.

The project follows a progressive, hands-on approach, focusing on building reliable AI applications through model integration, structured responses, tool usage, validation, and evaluation.

## 🎯 Project Objectives

- Understand the fundamentals of LLM application architecture.
- Develop a bilingual AI service assistant.
- Explore model integration and tool-based interactions.
- Implement input validation and structured response handling.
- Apply testing and performance evaluation techniques.
- Document development progress and experimental results.

## 📚 Labs & Homework Progress

### 🔹 Day 1 – Foundations of LLM Application Engineering

**Lab 1: Building a Basic Service Assistant**

Developed a foundational bilingual service assistant using a deterministic `FakeClient` to simulate model responses.

- Implemented structured responses and input validation.
- Generated unique trace identifiers and measured response latency.
- Verified predefined Arabic and English service responses.
- Executed baseline tests and generated JSON results.

**Homework 1: Real Language Model Inference**

Explored real language model inference using the pretrained `google/flan-t5-small` model.

- Loaded and executed the model locally on CPU.
- Applied tokenization and generated a response using synthetic service context.
- Compared real model generation with predefined `FakeClient` responses.
- Recorded inference measurements and exported results in JSON format.
